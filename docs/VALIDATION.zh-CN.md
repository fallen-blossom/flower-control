# 实际测过什么

[English](VALIDATION.md)

下面的真实任务结果来自加入 Claude Code 和反重力适配之前的 Codex 安装基线。新增适配及其对共用代码的修改尚未构建、测试；另一台干净 Windows 电脑的完整首次安装也还没有做。

本次采用 OSWorld 三题、WebVoyager 一题，加八项 Flower 日常专项。模型是 GPT-6.1 Sol、Medium；Computer 对照使用同一 Windows 桌面的 Codex 官方工具。没有跑上游完整虚拟机环境或评分器，不当作排行榜复现。

已经完成的工作包括表格补空格、公式和两张图表，Paint 绘图交给 Writer，arXiv 检索，网页编辑和真实 Python 运行，下载／上传内容逐字节核对，桌面虚拟列表与所属弹窗，控件重建后继续，以及 Web／App／Computer 三通道 Jev 开关对照。

Jev 在工具里直接执行合法选择，不再交给主模型逐步批准。三次故障测试都真的发了 HTTP 请求，在等待时关闭 Jev，迟到结果没有执行旧动作；另一次真实在途 Stop 也丢弃旧结果，正常继续并重新观察后才做新的保存。

保留的失败和缺口：文档题 52 词分类正确，但颜色没达到固定精度，所以不算通过；AI 环境在 Brave 更新后打不开的 bug 已安装修复并实际重开，但 X 仍有登录提示；所属弹窗边框问题已修，真实驱动复验四阶段 4／4／4／0；Computer 参数说明修好后，一次真实 Jev 请求完成一次点击，独立计数为 1。

四聊天都做成了各自任务，但没有自然形成前台排队争用，不能说这个场景已验。个人环境因测试聊天未获授权而没有试，干净电脑首次源码安装也还要补。单次速度不能推导整体加速，更不能推出所有任务 95% 成功或 Jev 一律 0.5 秒。

源码预览包含所属模态布局和 closed 浏览器身份恢复的小回归集，装好固定依赖后可运行：

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```

它不启动浏览器、不输入键鼠，只验证这部分逻辑，不替代上面的真实工作链。
