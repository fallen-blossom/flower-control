# 权限与设置

[English](PERMISSIONS.md)

Flower 当前有四档可选权限。它们是本地设置，但每次选择目标、启动程序和执行动作时都会重新检查。保存过某一档，不等于以后每个任务都永久获准。

## 打开设置

右键 Flower 托盘图标，选择**设置**。当前原生助手的界面以中文为主。

更改通常先进入共用草稿。可以切换页面，切换不会丢弃草稿。按**Ctrl+S**或点击页面上的保存按钮才会应用。有未保存修改时关闭设置，会询问保存、放弃还是返回；直接选择放弃或关闭不保存，会丢掉草稿。并非所有普通编辑都保证崩溃或重启后恢复；受支持的角色交接会把草稿带到新的设置界面并明确提示。详情对话框里的 **Ctrl+C** 只复制说明，不修改权限。

有些动作是立即执行，不走普通草稿保存：Stop、Computer 暂停、打开浏览器资料，以及部分 UAC/准备维护按钮会明确标注。不要把设置页上的每个按钮都当成 Ctrl+S 后才生效。

档位或名单保存可能因为保存版本已变化、目标身份不明、配置损坏、已有 Stop 未解除而被拒绝。重新打开设置、读取当前保存状态，不要反复强推旧草稿。

## 四个可选档位

界面编号只是展示标签。内部值列在这里，方便对照源码和 status。

| 界面档位 | 内部值 | 名称 | 普通窗口 | 管理员窗口 | 管理员启动 | 三通道效果 |
| --- | ---: | --- | --- | --- | --- | --- |
| 01 | -1 | 完全停止 | 否 | 否 | 否 | Web、App、Computer 全部停止派发 |
| 02 | 0 | 普通控制 | 是 | 否 | 否 | 只处理普通目标 |
| 03 | 1 | 管理员窗口 | 是 | 是 | 否 | 可观察和操作已经打开的管理员窗口，但不启动管理员进程 |
| 04 | 2 | 管理员执行 | 是 | 是 | 是，按本地策略 | 增加有边界的 High 启动；UAC 安全桌面仍冻结 |

01 完全停止会显示 disabled 类图标，不能只看“01-normal”文件来推断权限。可用状态下，02、03、04 分别主要映射到 `02-normal`、`03-admin-window`、`04-admin-launch`；暂停、不可用和配置损坏会切到 disabled/fault。保存档位和图标状态不是同一个字段，必须同时看托盘文字和状态页。

高档位包含低档位能力，它们不是相互叠加的独立开关。

### 03 和 04 的差别

**03 管理员窗口**：目标窗口已经以管理员权限打开，Flower 可以去读取和操作它，但这一档不负责创建一个新的管理员进程。

**04 管理员执行**：增加管理员程序的启动路径。启动必须匹配当前本地启动策略和精确程序身份，并重新检查当前档位、Stop、目标绑定和黑名单。

04 **不等于**“可以乱点所有 UAC 提示”。旧系统接管/UAC 路线已冻结，也没有新的可选启用入口。历史记录可以保留用于审计，但不能当成新权限。

## 几份名单分别管什么

- **程序黑名单**：匹配到的程序或窗口条件直接拒绝。黑名单优先于允许名单和任务授权。
- **管理员窗口黑名单**：单独限制管理员窗口层。
- **管理员启动名单**：04 使用的精确程序记录，不会自动批准启动器拉起的子程序或关联程序。
- **工作授权**：04 的另一种模式，绑定具体任务、程序、参数和目录，不会悄悄把所有程序变成白名单。

把程序加入名单草稿不会启动它；保存后还要在实际启动和动作时再次检查。

### 04 最小配置步骤

1. 打开**设置 → 权限**，选择 **04 管理员执行**，保存基础档位。
2. 名单方式：切到管理员启动名单，点“程序操作”里的**按键选择窗口**（优先）或选择程序文件；核对完整路径和程序身份，只把无参数规则加入草稿。按钮文字以当前设置页为准。
3. 按 **Ctrl+S** 保存。加入名单只在以后允许请求精确启动，保存本身不会运行程序。
4. 回到对话，让 Codex 对明确程序发一次有界启动请求；它会重新检查 04、Stop、名单或工作授权、目标身份和参数。

工作授权方式：在对应 04 设置中选择**按工作授权**，保存模式，再点**启用工作授权**，并在本机确认页面中分别允许需要的宿主。它绑定任务、程序、参数和目录，不是放行一切程序。新启用路线尚未就绪时页面会拒绝并保留原选择。

聊天里的 AI 不能直接写入受保护的权限文件。不要让它代改权限文件，要用你自己的 Windows 账号打开托盘设置。

## Stop、暂停和 01

- **01 完全停止**：Web、App、Computer 全部不派发。托盘、设置和 Stop 仍可用。
- **全局 Stop**：单独的本地停止状态，不是按 Ctrl+Alt+9 产生的状态。它存在且可恢复时，托盘会多出**继续全部写入**；没有这一行时不要手改状态文件，要按 status/错误证据和受支持的维护恢复处理。
- **Computer 暂停**：只拒绝新的 Computer 鼠标键盘操作，App 和 Web 可以继续。用托盘里的**暂停使用 Computer Use／继续使用 Computer Use**切换。
- **Ctrl+Alt+9、HUD Stop、托盘“停止 Computer Use”**：结束当前 Computer 操作并释放按键；不会改变已保存档位，也不会创建全局全部写入 Stop。
- **Computer 停止后的继续**：必须重新选择/观察并重新执行；不会重放上一次观察或结果未知的动作。

要离开 **01 完全停止**：打开**托盘 → 设置**，选 02、03 或 04，再按 **Ctrl+S** 或页面保存按钮。改档位不会清除单独的全局 Stop，普通“继续”也不会恢复已经撤销的聊天授权。

Stop、暂停、配置损坏、助手不可用或源码准入失败时，都应保持 fail-closed。状态不确定就停下来检查，不要重试动作。

## 六个托盘图标文件不是六档权限

图标资源有六种视觉状态：

```text
01-normal
02-admin-window
03-admin-launch
04-system-uac
05-disabled
06-fault
```

这些名字只是托盘显示状态，不是六档可选权限。

- 当前可选档位对应 normal、administrator-window、administrator-launch 三类视觉。
- `disabled` 表示停止或不可用。
- `fault` 表示配置损坏或无法读取。
- `system-uac` 是为冻结的旧视觉路线保留，不是新增的 04 功能。

保存档位和图标状态有关，但不是同一个字段。判断时同时看托盘文字和状态页。

## 当前安全边界

- 聊天/会话授权不等于 Windows 管理员权限。
- 助手连接成功不等于所有目标动作都安全。
- 密码输入、跨用户提权、UAC 安全桌面点击和无限持键不在本版承诺内。
- 管理员工作来源不可用或 pending 时保持 fail-closed。不要为了把状态弄绿而伪造、重放或消费 pending 管理员消息。
