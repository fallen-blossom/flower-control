# Flower Control 0.1.0 预览版

[English](RELEASE_NOTES.md)

Flower Control 给 Codex 提供操作网页和 Windows 软件的工具。告诉它要做什么，就能填写表单、使用菜单、编辑网页、上传文件，或者拖动画布里的物体。

- **Web** 通过 Playwright 读取和操作网页元素，当前只支持 Brave，后续计划扩展其他浏览器。
- **App** 通过 FlaUI 读取和操作 Windows 控件，包括输入框、列表、菜单和弹窗。
- **Computer** 截取选定窗口后操作鼠标和键盘，适合画布、拖拽、快捷键，以及控件读不出来的界面。

控制状态保存在本机。Flower 不采集使用统计，不上传崩溃报告，不接收远端配置，不自动更新。你所用的模型服务和正常网站访问仍会联网。可选 Jev 接收短目标和候选文字来选择操作对象，Flower 可以在同一次调用里直接执行；新安装默认关闭 Jev。

**Ctrl+Alt+9 是紧急停止键。** Computer 控制时显示流动边框、耗时和 Stop 按钮，停止后重新观察目标再继续。已知顺序的机械步骤可以批量执行。

临时浏览器相互独立，AI 环境保留自己的登录状态，个人环境每个聊天授权一次。要通过 Web 使用已登录账号，先在对应 Flower 环境登录；日常浏览器的登录状态不会自动复制过来。

首发是 **MIT 许可的 Windows 源码预览版**，包含中英文安装、登录、隐私和测试说明。管理员助手根据你的 Windows 账号和源码目录在本机编译、准备；没有现成的二进制一键安装包。Codex 本身不用以管理员身份运行，当前助手托盘菜单仍为中文。

另附 Windows 原生 Claude Code 和反重力 IDE 的源码适配，**尚未构建或测试**。反重力按连接处理任务，没有每聊天隔离，不开放个人浏览器工具。反重力独立 CLI、SDK 和云端入口暂不支持。

已有 Codex 实测包括表格、文档、绘图、网页编辑、文件交接、桌面列表和弹窗、停止后继续，以及三通道 Jev。这些结果来自新增宿主适配之前的安装基线，文档着色题没有达到要求的颜色精度。干净电脑首次安装和后续共用代码改动仍需验证，不宣传总体成功率或排行榜成绩。

下载 `flower-control-0.1.0-preview.1-source.zip`，用 `SHA256SUMS.txt` 核对文件。先看[安装教程](INSTALL.zh-CN.md)，再看[浏览器登录](BROWSER_PROFILES.zh-CN.md)；[测试说明](VALIDATION.zh-CN.md)记录实际覆盖，[隐私说明](../PRIVACY.zh-CN.md)解释联网和本地数据。

问题请提交到 [GitHub issues](https://github.com/fallen-blossom/flower-control/issues)，附最小复现，不上传密钥、浏览器数据或私人截图。
