# Sharing Flower Control

These posts are ready to copy. They have not been posted on social media.

## English

Flower Control gives Codex three ways to use websites and Windows apps: webpage elements, desktop controls, and screenshots with mouse/keyboard input. Local state, no Flower telemetry, Ctrl+Alt+9 for Computer-only stop; the unpublished candidate adds Ctrl+Alt+Shift+9 for all-channel Stop. Optional Jev. Windows source preview with EN/ZH guides.

https://github.com/fallen-blossom/flower-control

Follow-up: Web currently supports Brave. To reuse a login, sign in once in Flower's dedicated browser profile. Claude Code and Antigravity source adapters are included but untested.

## 简体中文

Flower Control 给 Codex 提供三种操作方式：Web 直接操作网页元素，App 操作 Windows 控件，Computer 看截图后点击、输入和拖拽。控制状态留在本机，不加遥测，Ctrl+Alt+9 停 Computer，未发布候选另有 Ctrl+Alt+Shift+9 全通道停止，Jev 可选。首发是源码预览版，附中英文安装和登录教程。

https://github.com/fallen-blossom/flower-control

补充：Web 当前只支持 Brave，要在 Flower 的独立浏览器环境登录一次才能复用账号。另附 Claude Code 和反重力的未测试源码适配。
