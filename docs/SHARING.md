# Sharing Flower Control

These drafts are ready to copy. They have not been posted on social media.

## English

Flower Control gives Codex three local ways to use websites and Windows apps: managed Web profiles, Windows accessibility controls, and selected-window Computer input. It has four visible permission tiers, local Stop and Computer pause, deny lists, and a frozen UAC secure-desktop boundary. This is a Windows 11 x64 source preview with English and Simplified Chinese install, permission, usage, and troubleshooting guides.

https://github.com/fallen-blossom/flower-control/releases/tag/v0.1.0-preview.3
