---
name: flower-control
description: Operate temporary or AI Brave environments and selected Windows windows through Flower's local Web, App and Computer tools.
---

This is a reduced Antigravity Windows IDE preview. Web operates Brave page
elements; App operates accessible Windows controls; Computer captures and sends
keyboard/mouse input to a selected window. Use the actual tools discovered in
this connection. The same fixed Flower helper serves the supported hosts.

The scope is an MCP connection, not an individual Antigravity chat. Personal
Luohua browser tools and per-chat private grants are unavailable. Use temporary
or AI-dedicated browser environments. Select the intended App or Computer window
explicitly. Each channel has its own connection and target scope. Do not claim
an origin probe proves chat isolation. Do not use this preview for concurrent
chats relying on different private window permissions.

Never set flower_origin. The local adapter supplies it after independently
verifying the actual Antigravity process through the administrator helper.
Observe the target, use the current revision, dispatch once, and check the new
state. Query action_id before replaying an unknown action. Ctrl+Alt+9 stops writes
across hosts. Stop, pause, input release and optional Jev keep their existing
behavior; mechanical steps do not require an extra model review each time.

No Flower telemetry or cloud bridge is added. Results still enter the configured
Antigravity model service. Jev sends its approved task data only when enabled.
Do not install/update the helper, broaden its pinned host list, clear Stop or
unknown records, or enable private browser tools to get around an error.
