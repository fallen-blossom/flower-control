Flower Control 0.1.0：从安装到第一次使用

发行状态：0.1.0 Setup 与发行资产尚未公开；当前 preview.3 是源码快照。
本版未签名。正式发布后，从官方 Release 下载实际 Setup 与 SHA256SUMS.txt，核对 SHA；Windows 未知发布者与 UAC 由你人工判断，不添加信任根或关闭保护。
官方 Release：https://github.com/fallen-blossom/flower-control/releases

安装：
1. 以日常账号运行 Setup。新安装选择尚不存在的专用根，如 D:\FlowerControl；程序、资料、大缓存与维护材料分别放在 Program/Data/Cache/Packages。
2. 审阅目录和宿主选项，自己确认 Windows UAC。安装器包含运行依赖，普通用户无需编译；Codex 与受支持浏览器需要已安装。
3. 在 Codex 插件设置中安装、启用 Flower Control，并确认宿主要求的 Hook 信任。市场登记不等于当前聊天已加载。
Windows TEMP 解包、系统登记和宿主缓存仍可能使用系统盘。取消或失败时保留原回执，恢复时继续同一计划，不反复重装。

第一次使用：
1. 花形托盘图标 → 设置。新安装默认 02 普通控制，已有档位保留；先使用自己新建的空白记事本和公开网页。
2. 新建 Codex 聊天，复制下面的提示词：

请分别读取 Flower Web、App、Computer 的 flower_status，核对实际加载版本、执行器、权限和停止状态。列出记事本窗口，让我辨认新建的空白文档，再绑定它，输入“Flower 测试成功”并读回。不要保存或关闭文档。完成后结束控制，释放输入并保留文字。遇到 Stop、拒绝或未知结果不要重放。

3. 再让 Flower 临时浏览器打开 https://example.com、读取标题，完成后只关闭本次临时会话。需要个人浏览器资料时，先明确授权当前聊天和对应浏览器。

停止与设置：
- Ctrl+Alt+Shift+9 或托盘/设置紧急按钮：停止全部 Flower 新写入，需在本机明确恢复。
- Ctrl+Alt+9、HUD Stop、Computer 暂停：只影响 Computer 输入，App/Web 仍按各自权限工作。
- 热键冲突会显示警告，仍可使用按钮；恢复后先重新观察，不重放未知动作。
- 档位按钮立即生效；名单等普通编辑和导入草稿需要 Ctrl+S。设置还提供脱敏诊断、普通偏好备份和空间审阅，不默认录屏或上传。

更新与卸载：
用 Setup/维护入口更新，不直接搬动已安装根。若找到未完成的原计划，先核对提示中的目标版本并完成原操作，再决定升级。
卸载入口：Windows 设置 → 应用 → 已安装的应用 → Flower Control → 卸载。
默认保留个人资料、缓存、权限、Stop、unknown、审计和恢复记录；程序文件按准确范围进入回收站，失败不会改永久删除。新布局完成卸载后，可另行审阅确认 Data/Cache 回收；Program 内的受保护状态仍保留。取消个人回收会停止后续项，不强杀正在处理的一项。

验证状态：源码/隔离检查和短合成帧编码器测试已做；最终 0.1.0 安装、真实 High 控制、宿主信任/加载、升级恢复与卸载尚未验证。历史预览实测不代表本版已通过。
