# Changelog

## 0.1.0-preview.3 — 2026-11-04

First complete public source preview after the B46-r6 integration line.

- Four visible permission tiers: 01 fully stopped, 02 ordinary control, 03 administrator windows, and 04 administrator execution. The legacy system-takeover/UAC route remains frozen.
- Local tray settings for tier selection, deny lists, administrator-window policy, administrator launch records, privacy masks, Stop, and Computer pause.
- Web, App, and Computer channels with loaded-source, on-disk-source, helper, origin, and effective-control status.
- Managed Brave, Edge, and Chrome profiles with temporary, AI, and per-chat Luohua access.
- Bounded Computer input, HUD and tray Stop, Ctrl+Alt+9, and fail-closed recovery without automatic replay.
- Rewritten English and Simplified Chinese installation, permission, usage, troubleshooting, browser-profile, and release documentation.
- Public source export with a per-file SHA-256 manifest and a GitHub Release archive.

This remains a source preview. It is not a signed one-click installer and does not include clean-PC unattended acceptance.
